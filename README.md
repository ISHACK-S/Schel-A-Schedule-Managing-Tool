# Schel

Schel is a console-based schedule management application built using Java 21 and Supabase. It provides a simple menu-driven interface for managing schedules while demonstrating object-oriented programming principles and REST API integration.

## Features

- User Registration and Login
- Secure Password Hashing (BCrypt)
- Schedule CRUD Operations
- Supabase PostgreSQL Integration
- Menu-Driven Console Interface
- Layered Architecture (Controller, Service, Repository)

## Tech Stack

- Java 21
- Maven
- Supabase (PostgreSQL)
- Supabase REST API
- Jackson
- BCrypt
